## <img src="https://img.shields.io/badge/-%20-ED8B00?style=flat-square" height="15" align="absmiddle"/> Sobre o projeto

Repositório de estudos em **Java** com exercícios práticos de lógica de programação. Ele registra a evolução desde os fundamentos (entrada de dados, condicionais e estruturas de seleção) até os primeiros conceitos de **programação orientada a objetos**.

---

## <img src="https://img.shields.io/badge/-%20-ED8B00?style=flat-square" height="15" align="absmiddle"/> Conteúdo

| Arquivo | Tema |
|:---|:---|
| `exercicio3.java` a `exercicio14.java` | Entrada de dados com `Scanner`, operações aritméticas e condicionais |
| `switch1.java` a `switch3.java` | Estruturas de seleção com `switch` (ex.: dias da semana) |
| `bonus.java` | Cálculo com coordenadas de pontos no plano cartesiano |
| `exercicioCarro/` | Orientação a objetos: classe `Carro` com atributos, encapsulamento e validações |
| `input04/` | Leitura e processamento de arquivos de texto |

---

## <img src="https://img.shields.io/badge/-%20-ED8B00?style=flat-square" height="15" align="absmiddle"/> Como executar

**Pré-requisito:** JDK 11 ou superior.

```bash
# Clonar o repositório
git clone https://github.com/GustavoHermogenes/Learning-Java.git
cd Learning-Java

# Executar um exercício (Java 11+ compila e roda direto)
java exercicio3.java

# Exercício com mais de uma classe
cd exercicioCarro
javac *.java
java Main
```
